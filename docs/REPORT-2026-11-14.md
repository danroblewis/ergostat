# ergostat: what was built on 2026-11-14

For the owner, on their return. The detail is in `README.md`, `docs/DESIGN.md` and
`docs/cli-rounds.md` (twenty rounds of review: pretend users, three independent reviewers, two code reviews, and a
real Supervisor session).

## Try it

```bash
cd ~/ergostat
scripts/demos.sh start        # ten demos, each with its page (the URLs are printed)
scripts/demos.sh list
cd ~/ergostat-demos/ops && ~/ergostat/.venv/bin/ergostat            # the status
~/ergostat/.venv/bin/ergostat system --all --blocks                  # every loop as a block diagram, in text
scripts/demos.sh stop
```

The demos keep their records under `~/.ergostat/` when run this way (`ERGOSTAT_HOME` changes it).

## What exists

- **The model**, `ergostat.toml`: stocks, flows, disturbances, valves, sensors, controllers,
  agents, systems; loops are derived; `ergostat check` says what does not resolve and which
  loops cannot close, and how to fix each.
- **Plain jobs**: an agent filling one sensor or one valve may print a bare number, so a crontab
  one-liner (`find ... -delete -print | wc -l`) is an agent as it stands (the `plain-crontab` demo).
- **The runner**: agents on `every`, `cron` or `on` (event types, optionally `@item`), each run in
  its own process group with a timeout, its lines validated (a bad line is refused or reported,
  never lost), one runner per repository (a locked pid file), the model picked up live.
- **The record**: events and measurements in two SQLite stores, kept 30 days (the model's
  history and each loop's last crossing kept whole), long spans read in buckets.
- **The state estimate**: stock values, flow rates (declared, measured, or from valve openings),
  disturbances estimated from residuals, residuals flagged only when they persist, e = r − y, the
  tolerance as a hysteresis band, time off per loop, and hints: a cheaper agent could fill a
  role (the ladder), a loop is saturated (its valve is smaller than its load), a loop samples
  too slowly.
- **The command line**: the status (`--watch`, `--exit-code`, `--at`, `--since`, `-s`), `system`
  (drawn in text, `--blocks`, `--wiring`), `loop`, `agent` (`--now` runs one), `event --follow`,
  `item`, `residual`, the parts, `check`, `run`, `projects`, `chat` (the Supervisor). `--json`
  everywhere.
- **The web page**: the control diagram laid out by ELK (stocks as tanks, pipes, valves,
  disturbances, sensors, controllers, agent badges by rung and schedule, systems as outlines,
  loops coloured by status), the block view (classic feedback block diagrams), the wiring view
  (agents, and the cycles among them, declared or not), Loops, Agents (the ladder), Parts, Record,
  Residuals, Check, a Guide; a time slider for any past moment; SVG and PNG export; light, dark,
  phone.
- **Snapshots**: `ergostat snapshot` writes the page and what it shows to one HTML file (about 2 MB)
  that opens offline: the diagrams to attach to a document or a ticket.
- **Docs**: `docs/writing-agents.md`, `docs/ai-agents.md` with `examples/ai-controller.sh` (a
  controller filled by `claude -p`), `docs/DESIGN.md`.
- **Tests**: 79 unit and integration tests; `scripts/demo_check.py` runs a fresh copy of every
  demo and checks its pages in a headless browser.

## Decided while you were away (change any of them)

- Python 3.12+, standard library only at runtime; `uv`, pytest, ruff.
- The model is `ergostat.toml` in the repository; state in `~/.ergostat/<name>-<hash of the repo path>/`.
- The web page is read only, on 127.0.0.1:8781 (or the next free port).
- e = r − y (the control convention), and the tolerance is a one-sided hysteresis band.
- A residual is flagged only when the recent half of the window shows it too.
- `keep = "30d"` by default.
- Commits on `main` as checkpoints; nothing pushed; no remote. The demos are local git
  repositories under `~/ergostat-demos/`.

## Open: yours to decide

- **Approvals.** Valves have a mode (auto, advise, manual) that is recorded and drawn, but nothing
  waits for you. Approving at a valve would be the command line's one write.
- **Discovery.** Inferring the control system from measurements alone (SD, Kalman, LNA). The
  record keeps declared and measured apart so it can be added.
- **Cascades.** A controller setting another's setpoint.
- **One page for several repositories.** `ergostat projects` and the header switcher exist; a
  single page drawing them all does not.
