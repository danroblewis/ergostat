# uPlot 1.6.31 (vendored)

The charts beside the model (docs/proposals/charts.md) are drawn with uPlot, by Leon Sorokin
(https://github.com/leeoniya/uPlot): small, fast time series on a canvas, with synchronised cursors.
`uPlot.iife.min.js` is copied unchanged from the npm package `uplot@1.6.31` (`dist/uPlot.iife.min.js`,
sha256 `2d27e8ad3d228164525ce213f9dc716f39b4e3aee0cc773fb3491c96cf4921a2`), so the page loads
nothing from elsewhere and a snapshot carries it inline. Its stylesheet is not copied: the few rules
it needs are in `style.css`, written with the page's tokens. Licence: MIT (LICENSE).
