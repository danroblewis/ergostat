# 24 loops, for the layout

A made-up platform of six systems with four loops each, some in series: what the diagram does at scale.

```bash
cd examples/big
ergostat check
ergostat run          # prints the page's address
ergostat              # what needs attention
ergostat run --stop
```

Things to look at:

- The first view keeps text legible and says when more lies beyond the edge; `fit` shows it all.
- The blocks view groups the loops by system.

Shows: layout at scale.
